# Project Documentation

| Field | Details |
|---|---|
| Team ID | SWTID-2026-7634 |
| Project Name | ComicCraft: AI Comic Creation Assistant |
| Team Leader | C Nithya Shree |

| Section | Details |
|---|---|
| Overview | ComicCraft converts a story idea into a scripted, illustrated and laid-out comic using generative AI |
| Team | C Nithya Shree (Leader), Lakshana, A Pavithra, Priyanga V |
| Setup | Install Python, run `pip install -r requirements.txt`, add the API keys as environment variables |
| Run | Use `streamlit run app.py` and open the local address in the browser |
| How to Use | Enter a story idea and style, review and edit the script, generate panels, check the layout and download the comic |
| Limitations | Image quality and character consistency depend on the AI model; unsafe prompts are blocked |
| Future Scope | Multi-page comics, more art styles, voice narration and regional language support |
