# Solution Requirements

| Field | Details |
|---|---|
| Team ID | SWTID-2026-7634 |
| Project Name | ComicCraft: AI Comic Creation Assistant |
| Team Leader | C Nithya Shree |

## Functional Requirements

| FR No. | Functional Requirement | Sub Requirement |
|---|---|---|
| FR-1 | Story Input | Enter a story idea, genre and number of panels |
| FR-2 | Script Generation | Generate characters, scenes and dialogue for each panel |
| FR-3 | Script Editing | Let the user edit the script before artwork is created |
| FR-4 | Artwork Generation | Create an image for each panel in the chosen art style |
| FR-5 | Character Consistency | Reuse the same character descriptions in every panel |
| FR-6 | Layout and Bubbles | Arrange panels and add speech bubbles with dialogue |
| FR-7 | Export | Download the comic as PDF or PNG images |

## Non-Functional Requirements

| NFR No. | Non-Functional Requirement | Description |
|---|---|---|
| NFR-1 | Usability | Simple screens usable without art or technical skills |
| NFR-2 | Content Safety | Blocks unsafe or inappropriate story prompts |
| NFR-3 | Reliability | Panels match the script and chosen style |
| NFR-4 | Performance | Script within 10 seconds and each panel within 30 seconds |
| NFR-5 | Availability | Works reliably during normal use |
| NFR-6 | Scalability | Can support more users and styles with cloud deployment |
